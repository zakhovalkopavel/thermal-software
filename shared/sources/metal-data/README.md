# Metal-data sources

- `raw-tables/` — OCR / transcribed property and composition tables (ASM Handbook Vol. 1,
  Abu-Eishah 2001 pure-metal λ fits). Kept verbatim as the synthesis input.
- `metal-conductivity-abu-eishah.json` — join file generated by `make metal-data-build`
  from the pure-metal tables (fed into compound-data).

Processed output: `shared/processed/metal-data/`. Spec: `docs/scripts/METAL_DATA_SPEC.md`.
